# 🛍️ ShoppyGlobe

ShoppyGlobe is a modern React-based e-commerce web application built using **React, Redux Toolkit, React Router, Tailwind CSS, and DummyJSON API**. It allows users to browse products, search products, view product details, manage a shopping cart, and place orders through a responsive checkout page.

---

## 🚀 Features

- 🏠 Home page displaying all products
- 🔍 Search products by name
- 📄 Product Details page
- 🖼️ Product image gallery with zoom and fullscreen preview
- ⭐ Dynamic product ratings using React Icons
- 🛒 Add products to Cart
- ➕ Increase / Decrease product quantity
- ❌ Remove products from cart
- 💰 Order Summary with total price calculation
- 📦 Checkout page with customer details form
- ✅ Order confirmation using React Toastify
- 📱 Fully Responsive Design
- ⚡ Lazy Loading using React.lazy & Suspense
- 🚫 Custom 404 Not Found Page

---

## 🛠️ Technologies Used

- React.js
- Vite
- React Router DOM
- Redux Toolkit
- React Redux
- Tailwind CSS
- React Toastify
- React Icons

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/kapil234/ShoppyGlobe.git
```

Go to the project directory

```bash
cd shoppyglobe
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
